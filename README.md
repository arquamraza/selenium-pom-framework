# Selenium POM Framework - Amazon Automation

A professional UI Automation Framework built with Python, Selenium & Pytest using Page Object Model (POM).

### Tech Stack
- Python 3
- Selenium WebDriver
- Pytest
- Page Object Model
- Docker Ready

### Project Structure
- `pages/` - All Page Objects (LoginPage, HomePage)
- `tests/` - Test Cases
- `conftest.py` - Browser setup and fixtures
- `requirements.txt` - Dependencies
- `Dockerfile` - For Docker execution

### How to Run
1. Clone repo:
   git clone https://github.com/arquamraza/selenium-pom-framework.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run tests:
   pytest -v

### Features
- POM Design Pattern
- Cross-browser support
- Clean and reusable code
- Easy to scale for any website
